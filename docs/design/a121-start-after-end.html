Data de início depois da data de fim

Com a data de fim aprovada, alguém pode editar o protocolo e pôr a data de início depois do fim. Nesse caso Salvar para, nada é gravado, e o aviso deixa a pessoa resolver ali mesmo. Claro e escuro; o inglês está em letra pequena embaixo de cada celular.

Já decidido pela lógica (não precisa responder)

  • O título diz o que aconteceu, com o triângulo de aviso, como as outras telas em que algo não foi salvo.
  • O texto mostra as duas datas, para a pessoa ver o conflito sem procurar.
  • A data de fim continua sendo editada na roda já aprovada; o formulário de Editar não ganha campo novo (você escolheu a opção A).

1 · Ao tocar Salvar com o início depois do fim

A pessoa mudou a data de início do Goli para 20 de jan. de 2027, mas o protocolo tem data de fim em 15 de jan. de 2027. Salvar para e nada é gravado; aparece este aviso sobre o formulário.

Ao tocar: Mudar a data de fim abre a roda de datas (passo 2). Voltar fecha o aviso e deixa o formulário como estava, para mudar a data de início.

2 · Mudar a data de fim

A mesma roda de datas aprovada para a data de fim, aqui só aceitando datas a partir do novo início. "Sem data de fim" tira a data, como na página do protocolo.

Ao tocar: Salvar data de fim grava a nova data de fim e, em seguida, o protocolo com a nova data de início (os dois juntos). Sem data de fim tira a data e salva. Voltar volta ao aviso do passo 1.
