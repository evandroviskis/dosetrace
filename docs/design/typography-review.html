6 · What changes, for your approval

  1. Font split (Impeccable, iOS and Android): reading text, labels and buttons in the phone's own font (San Francisco / Roboto); Geist for screen titles and the big numbers; Geist Mono only for measured values. The alternative is Geist for everything, as in v3; Taste endorses Geist, but Impeccable's native rules say the system font carries the interface. Recommended: the split.
  2. One role scale of nine roles (section 4) replacing 32 sizes; nothing under 11 pt; body 17 pt.
  3. Text size: every screen tested at the largest text sizes; no text in fixed-height boxes. The stress test shows the side-by-side tiles break at 135% ("Dose accumulation" splits mid-word), so they stack from about 130% text size up.
  4. Monospace only on values (84.6 kg, 2,810 kcal, 20:00, 50.0 u). Sentences such as "In progress · weigh in Oct 12, 2026" go back to the reading font, with aligned digits. This corrects my own v3 mockups.
  5. Tracking: big numbers at −0.03em, not the −0.045 to −0.055em I used (Impeccable's floor is −0.04em).
  6. Animated numbers (Emil): Today's ring and counts replay from zero every time Today opens; a screen opened many times a day should not replay them. Show the numbers at rest; animate only when a value changes (a dose logged), and never with Reduce Motion on.
  7. Fonts loaded: only the weights used (Geist 300 and 600, Geist Mono 400 and 500 with the split). Today the app loads five weights, and every request for a light weight silently renders as regular.
  8. Later (layout, not type): Impeccable bans a small label above a heading, which is what Today's date line is. It stays under the layout freeze; noted for the Today layout pass.
