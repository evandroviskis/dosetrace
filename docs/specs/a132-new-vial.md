# Vial: New vial and Edit vial — A-132, AD-80

- source: founder 2026-10-20 (docs/decisions.md "A-132 picture approved"): screen 2 = A ("+ Novo frasco" on Today's card when the vial is past its window), screen 3 = "Novo frasco" on the protocol page for reconstituted vials too, screen 4 = the "Novo frasco" window texts and the card after saving, as drawn; both themes. Founder note: the control uses the app's own type (lib/fonts.js), same style as "+ Adicionar frasco". Registry: docs/review/features.md A-132.
- picture: docs/design/a132-expired-vial-new-vial.html (incl. its "Já decidido pela lógica" list: the one-vial alert opens that protocol's page; a new vial retires the old one with its leftover doses, never two active; "+ Adicionar frasco" opens the same "Novo frasco" window; after the last dose the window is unchanged).
- AD-80 source: founder 2026-10-26 ("A para os dois"): (1) "Editar frasco" = option A, a second button beside "Novo frasco" in the protocol page's vial block, for reconstituted AND ready-to-use vials; the edit windows as drawn (reconstituted: mix date, validity in days, doses already used, a mix date in the future refused; ready-to-use as drawn) and the results on the protocol page and Today's card as drawn; (2) the ready-to-use "Novo frasco" asks the new box's month/year with option A (the protocol form's pills, blank allowed), results with a date and blank as drawn. Picture: docs/design/ad80-edit-vial.html (incl. its "Já decidido pela lógica" list). Registry: A-158.
- decided by logic (AD-80, not drawn): a mix date is read in the current year; a day after today is refused, except that a vial mixed in an earlier year keeps that year when its day is already past (a December vial corrected in January), so opening and saving an unchanged window never refuses. Doses already used left empty = unchanged.
- code: lib/newVial.js (startNewVial, the one write for both vial types; vialPastWindow, showsNewVialButton, vialPromptKeys, oldVialNote, vialAlertTarget), lib/vialEdit.js (AD-80: showsEditVialButton, editVialStart, editMixDate, editVialPlan, applyVialEdit, the limits), lib/protocolForm.js (boxExpiresOn, shared with the form), screens/components/NewVialPrompt.js (NewVialPrompt and EditVialPrompt, shared by Today and the protocol page), screens/TodayScreen.js (card, alert, book page, last-dose prompt), screens/ProtocolsScreen.js (vial block, both windows), i18n/translations.js x6.
