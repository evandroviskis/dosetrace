## What the picture decides (summary)
- **AD-99 B (free):** one line right under the "Diário de exames" title, the same place for every plan: "2 de 3 leituras usadas este mês (exames, vacinas e frascos) · renovam em 1º de nov.". At 3 of 3 the count part is drawn in the attention colour, semibold; "+ Enviar" stays (a tap shows today's limit message). The free card below is unchanged.
- **AD-99 P2 (Premium):** "5 leituras usadas este mês (exames, vacinas e frascos)": the count only, never the 20, no renewal (AD-69).
- **Decided by logic in the picture:** the count adds labs, vaccine cards and vials, like the limit; the month is the server's (UTC); "renovam em" shows the first day of the next month; the app asks the server for this account's own count (the table is closed to the app); without internet the line does not appear, never a guessed number.
- **AD-100 B:** a "Mudar a data deste exame" button (calendar icon, well capsule) between the test's values and "Excluir este exame". It opens the app's window: calendar icon, the title, "Os 12 valores e as etiquetas deste exame passam para a nova data.", the app's date wheel (up to 30 years back, never a future day), Cancelar | Salvar. Save moves the whole test (every value) and its labels; the screen stays open on the test, now with the new date. Another test already on the new date stays its own card. The "Exame importado" message that said "abra o exame para definir a data correta" now leads to this action.
