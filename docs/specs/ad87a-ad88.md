# Reminder window end on iPhone (AD-87 A) + permission ask when protocols arrive (AD-88)

- source AD-87 A: founder 2026-10-15, Q10 / OPEN-06 = "A now, B next" (docs/decisions.md; OPEN-DECISIONS AD-87; DIVERGENCES DV-097): "the last notification of the window and a Today warning". Picture docs/design/ad87a-reminder-window-end.html; founder 2026-10-20 ("Pode seguir com as suas recomendações em todos"): "AD-87 A = A (the sentence joins the last dose reminder), texts as drawn". Ledger correction 8f21ca2: the reminder-window-end notification of DV-045 IS this approved AD-87 A. AD-87 B (server-sent iPhone reminders, docs/specs/server-reminders.md) is not part of this spec; SR-17 makes this the fallback later.
- source AD-88: founder 2026-10-15, Q11 (a) = A (docs/decisions.md; OPEN-DECISIONS AD-88; DIVERGENCES DV-054): "no notification-permission request at app open; it is asked when a protocol with a reminder time is first saved on the phone or arrives from another device (Android also via the reminder setup screen)". Founder 2026-10-20, 1.3.2 recommendations accepted: "the permission ask after protocols arrive on a new phone (AD-88)".
- decided by logic (not asked): only iPhone (Android renews in the background, 21 days); the sentence goes on the window's last MAIN dose reminder and its +5/+10 repeats, and only while a dose reminder is still owed after it (a course that ends inside the window gets no sentence: it would promise reminders that never come); the Today warning shows only when the 64 cap cut the renewed plan and its last dose reminder is 2 local days away or less (as drawn); the title says "today" / "tomorrow" / the weekday; the warning joins the other reminder warnings (two or more → the one combined card, council 3 decision 3); the AD-88 ask is the existing system dialog (no new screen or copy), only while the phone's answer is undecided.
- code: lib/notificationPlan.js (windowEndSlot), lib/notifications.js (iosDoseShares, syncAllDoseRemindersNow, scheduleDoseReminder windowEnd), lib/reminderHealth.js (shouldWarnWindow, windowAlertTitle, reminderWarnings), screens/TodayScreen.js (the Alerts card), i18n/translations.js (x6).
